
# VyshyvankaDaily

> Щодня - новий орнамент твоєї землі.

Щоденна платформа генеративного українського орнаменту: силует вишиванки, на якому щодня з'являється новий орнамент, прив'язаний до реального історичного регіону України з поясненням символіки, підтвердженим перевіреними джерелами.

Весь візуальний контент генерується алгоритмічно на основі математичних груп симетрії, якими формально описується традиційна вишивка — не UGC, не завантажені зображення. Кожен день детермінований: та сама дата завжди дає той самий результат.
