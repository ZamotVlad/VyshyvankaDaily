{% translate "Звідки ми беремо факти" %}

{% translate "Кожне джерело ми відносимо до одного з трьох рівнів надійності." %}

  • {% translate "Рівень А - музеї та їхні каталоги, наукові видання, державні установи, ЮНЕСКО і Національний перелік елементів нематеріальної культурної спадщини України." %}
  • {% translate "Рівень Б - Суспільне й регіональні медіа, коли в матеріалі говорить названий фахівець: музейник, етнограф, дослідниця чи майстриня." %}
  • {% translate "Рівень В - медіа без названого фахівця, блоги, магазини вишиванок. Нових фактів звідси ми не беремо, лише звіряємо з ними вже знайдене." %}

{% translate "Що показує розділ «Джерела»" %}

{% translate "Під текстом регіону чи статті є розділ «Джерела». На сторінках регіонів там лише джерела рівня А: назва праці, автор або установа, рік. У статтях блогу до них можуть додаватися матеріали рівня Б з названим фахівцем. В інших випадках джерела рівня Б допомагають перевірити факти й додати подробиці, а в тексті ми прямо називаємо, хто це сказав і де." %}

{% translate "Джерела подаємо текстом, без посилань. У статтях блогу можуть бути посилання на авторитетні ресурси: Вікіпедію, музеї, державні установи. На соцмережі й комерційні сайти ми не посилаємось." %}

{% translate "Факт, тлумачення і переказ" %}

{% translate "Символіка орнаменту - здебільшого тлумачення, і різні дослідники пояснюють той самий знак по-різному. Тому тлумачення ми подаємо з указанням, кому воно належить: «за поясненням музею», «на думку дослідниці». Легенди й повір'я позначаємо як переказ і не видаємо за встановлений факт." %}

{% translate "Коли джерела розходяться, наприклад у датуванні, ми пишемо про розбіжність або тримаємось версії надійнішого джерела. Те, що підтвердити не вдалося, до тексту не потрапляє." %}

{% translate "Кольори на сторінках регіонів" %}

{% translate "Основні кольори регіону - це палітра, з якої будується орнамент дня. У блоці «Також трапляються» - кольори, які джерела згадують для регіону, але які не є головними. Обидва переліки неповні: справжня вишивка знає більше відтінків, ніж можна звести до кількох зразків." %}

{% translate "Орнамент дня" %}

{% translate "Орнамент дня створює алгоритм. Він будує візерунок з мотивів, описаних для регіону, і фарбує його в палітру регіону. Це стилізація за мотивами, а не копія конкретної сорочки з музею. Для однієї дати результат завжди той самий." %}
